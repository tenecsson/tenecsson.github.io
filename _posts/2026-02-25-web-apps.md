GitHub Pages is great for static pages, blogs like this one, and even hosting your web apps. 

For example, this [repo](https://github.com/tenecsson/d3-force-app) has been configured to 
- use GitHub Pages for hosting
- automatically redeploy the site whenever there is a push to the main branch

The result is [a nice little app](https://tenecsson.github.io/d3-force-app/) that lets you visualize graphs from a JSON description.

All configuration is explained in the `README.md` of the aforementioned [repo](https://github.com/tenecsson/d3-force-app)
